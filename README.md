# Artisan Craft Studio

Собери сайт для продажи ремней ручной работы с теснением с дизайнерскими латунными пряжками собственного производства. Название мастерской - Мастерская Корякиных.  - (распиши структуру подробнее: не забудь - основная панель, каталог, карточка товара, корзина, хедер, футер, доставка, политика конфиденциальности и оферта) + небольшую админку, куда будут уходить заявки и можно будет добавлять и редактировать товары. Техническое задание

Сайт мастерской ремней и пряжек ручной работы

Стиль: атмосферный artisan luxury / dark craft / handcrafted premium

Платформа разработки: Lovable

1. Общая концепция

Сайт должен ощущаться не как классический интернет-магазин, а как цифровая мастерская автора.

Главная задача:

передать характер изделий,

показать ручную работу,

создать эмоциональное ощущение ремесла,

выделить уникальность пряжек и тиснения,

аккуратно вести пользователя к заявке.

Визуально:

премиальный минимализм,

кинематографичные крупные планы,

акцент на фактурах кожи и металла,

воздух и темный фон,

медленные анимации,

ощущение мастерской, а не каталога масс-маркета.
