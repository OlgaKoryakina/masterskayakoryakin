# Админка прямо на сайте

Админка уже работает на самом сайте по адресу `/admin` (masterskayakoryakin.lovable.app/admin) — это не панель Lovable. Сейчас там: заказы, товары (фото и видео), отзывы, часть текстов. План — сделать её полной и удобной.

## Что будет сделано

1. **Удобный вход**
   - Незаметная ссылка «Вход для мастера» в подвале сайта → страница входа.
   - Если вы вошли как админ, в шапке сайта появляется кнопка «Админка».
   - Логин и пароль остаются прежними (admin1964@admin.com).

2. **Новая вкладка «Аккаунт»**
   - Смена пароля (с повтором для проверки).
   - Смена почты-логина (придёт письмо для подтверждения на новую почту).

3. **Редактирование всех разделов сайта** (вкладка «Контент», разбита по страницам):
   - Главная: первый экран (заголовок, подзаголовок, кнопки, фото/видео фона), манифест (текст и фоновое фото), блок «От эскиза до готового изделия» (текст и фото), этапы процесса (названия, порядок, фото — можно добавлять и удалять этапы), блок индивидуального заказа, финальный блок (текст и фон).
   - О мастерской: тексты и фотографии.
   - Индивидуальный заказ: тексты и список вариантов кастомизации.
   - Доставка и оплата, FAQ (добавить / изменить / удалить вопросы), Контакты, подвал (соцсети, телефоны).
   - Политика конфиденциальности и оферта — полный текст.
   - Везде загрузка фото и видео с компьютера, с предпросмотром и заменой.

4. **Товары, заказы, отзывы** — остаются как есть (уже умеют несколько фото и видео, статусы заказов, модерацию).

## Технические детали
- Все тексты и медиа страниц хранятся в `site_content` (ключ на секцию); страницы читают их с запасным текстом по умолчанию, чтобы сайт не опустел.
- Медиа грузятся в существующее хранилище `product-images` через уже готовый компонент MediaManager.
- Смена пароля/почты — `supabase.auth.updateUser`.
- Кнопка «Админка» в шапке — по проверке роли admin.
- Изменений в правах доступа к базе не требуется (запись в `site_content` уже разрешена только админу).
