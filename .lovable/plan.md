## Цель
Заменить поддержку YouTube/Vimeo на ВК Видео при добавлении видео по ссылке в админке товаров.

## Что меняется

### 1. `src/lib/video-embed.ts`
- Удалить определение YouTube и Vimeo.
- Тип `VideoKind` становится `"file" | "vk"`.
- `detectVideoKind` распознаёт ссылки вида `vk.com/video...`, `vkvideo.ru/...`, `vk.ru/video...`.
- `getEmbedUrl` строит embed-URL для ВК Видео:
  - Из ссылок `vk.com/video-123_456` или `vk.com/video?z=video-123_456` → `https://vk.com/video_ext.php?oid=-123&id=456&hd=2`
  - Поддержать формат с `list=` / hash-параметрами (отбросить лишнее).
  - Вернуть `null`, если распарсить не удалось.

### 2. `src/components/admin/MediaManager.tsx`
- В блоке «Добавить видео по ссылке»:
  - Поменять placeholder на `https://vk.com/video-XXXX_YYYY` (пример ВК Видео).
  - Сообщения об ошибках: «Поддерживаются ссылки ВК Видео», «Не удалось распознать ссылку ВК Видео».
- В превью загруженных видео метка теперь показывает `VK` вместо `youtube/vimeo`.

### 3. `src/routes/product.$slug.tsx`
- Рендеринг embed-ссылок продолжает работать через `getEmbedUrl` без изменений логики (iframe), т.к. ВК Видео тоже отдаёт iframe-плеер. Проверить, что атрибут `allow` подходит (`autoplay; encrypted-media; fullscreen; picture-in-picture`) и `allowFullScreen`.

## Что не трогаем
- Загрузка файлов (drag-and-drop, прогресс, превью, удаление, обложка) остаётся как есть.
- Существующие сохранённые ссылки YouTube/Vimeo, если есть, перестанут отображаться как embed — на превью покажется иконка ссылки, но новых ссылок этих типов добавить будет нельзя. Пользователь может удалить их вручную.
