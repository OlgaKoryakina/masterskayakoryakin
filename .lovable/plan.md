## Цель
На странице «Контакты» (и в админке контента) добавить отдельные поля: **телефон**, **Telegram**, **Email**. Сейчас в админке поле `phone` подписано как «ВКонтакте», а отдельного телефона нет.

## Что меняется

### 1. Схема данных (без миграции БД)
Контакты хранятся в `site_content` под ключом `contacts` как JSON. Расширяем JSON новыми ключами, старые сохраняем для обратной совместимости:

```json
{
  "phone": "+7 ...",      // настоящий телефон (новое назначение)
  "vk": "https://vk.com/...",  // ВКонтакте (новое поле)
  "telegram": "@...",
  "email": "...",
  "city": "..."
}
```

Поле `phone` в админке раньше использовалось под VK — при первом сохранении админ сможет перенести значение в `vk` вручную.

### 2. Админка — `src/routes/admin.content.tsx`
В блоке «Контакты» сделать 5 полей:
- Телефон (`phone`)
- ВКонтакте (`vk`)
- Telegram (`telegram`)
- Email (`email`)
- Город / адрес (`city`)

### 3. Публичная страница — `src/routes/contacts.tsx`
Отрисовать строки в порядке: Телефон → ВКонтакте → Telegram → Email → Где мы. Телефон — кликабельная ссылка `tel:`, email — `mailto:`, VK и Telegram — внешние ссылки.

### 4. Футер `src/components/site/Footer.tsx` (если использует те же поля)
Проверить и при необходимости синхронизировать вывод (не меняя дизайн).

## Что НЕ меняется
- Дизайн, типографика, цвета.
- Форма заявки в корзине (`src/routes/cart.tsx`) — там отдельная пользовательская форма, её не трогаем.
- Структура таблицы `site_content`.
