## Что сделать

На странице товара (`src/routes/product.$slug.tsx`) добавить возможность открыть основное фото на весь экран по клику.

## Поведение

- Клик по большому изображению (блок `aspect-[4/5]`) открывает полноэкранный лайтбокс с этим фото.
- В лайтбоксе:
  - фото по центру, вписано в экран (`object-contain`), фон затемнённый (`bg-background/95`).
  - кнопка закрытия (✕) в правом верхнем углу.
  - если у товара несколько фото — стрелки ←/→ для перехода между ними + индикатор «2 / 5».
  - закрытие по клику на фон, по ✕, и по клавише `Esc`; навигация стрелками клавиатуры.
  - блокировка прокрутки страницы при открытом лайтбоксе.
- Миниатюры под фото продолжают работать как раньше (переключают активное фото; если лайтбокс открыт — синхронизируются).
- Видео не трогаем.

## Реализация

- Внутри `ProductPage` добавить состояние `lightboxOpen` и переиспользовать `active` как индекс.
- Использовать существующий `Dialog` из `src/components/ui/dialog.tsx` (`DialogContent` с кастомным классом на весь экран, без рамок), либо собственный простой overlay через portal — выберу `Dialog` для консистентности и встроенного управления Esc/focus trap.
- На превью изображение — добавить `cursor-zoom-in` и `onClick={() => setLightboxOpen(true)}`.
- Стрелки и счётчик показывать только при `product.images.length > 1`.

## Чего НЕ меняем

- Каталог (`catalog.tsx`), карточки списка — пока без лайтбокса (пользователь сказал «в карточках товара» = на странице товара). Если имелся в виду также каталог — уточнить после.
- Логику корзины, видео-эмбеды, медиа-менеджер.
